# R script and aggregated regional data used for analyses on trends and regional variation in antibiotic prescribing by dentists in Finland

## Paper
"Trends and regional variation in antibiotic prescribing by dentists in Finland, 2012-2025: a register-based study" by Laitala, Aarnio, Tuomilinna, Raittio and Leinonen in European Journal of Oral Sciences 2026.

## Files
- data.xlsx = aggregated regional dataset
- script.R = analyses and figure generation

## Requirements
R packages:
tidyverse, readxl, MASS, glmmTMB, ggplot2, ggpubr, sf, mapsFinland

## Reproducibility
Download data.xlsx to working directory.
Run script.R from the working directory.
Script saves the figures to the working directory.

See codebook section in script.R.
